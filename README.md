# نظام البحث عن الأصول - هيئة المساحة الجيولوجية

تطبيق بسيط باستخدام Streamlit يسمح لك بالبحث عن الأصل برقم فريد، ويعرض لك كافة التفاصيل مع إمكانية تحميل تقرير PDF.

## 📁 مكونات المشروع:
- `asset_info_app.py` : الكود الرئيسي للتطبيق.
- `assets_data.xlsx` : ملف بيانات الأصول (تأكد من تعبئته ببيانات صحيحة).
- `requirements.txt` : المكتبات المطلوبة لتشغيل المشروع.
- `README.md` : هذا الملف.

## 🚀 طريقة التشغيل:
```bash
pip install -r requirements.txt
streamlit run asset_info_app.py
```

## 📌 ملاحظة:
التقرير PDF إلكتروني فقط، وغير معتمد رسميًا.
